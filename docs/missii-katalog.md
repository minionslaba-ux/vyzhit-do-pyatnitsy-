## Известные несовпадения с правилами скилла

- «Закройте любую неделю» (задание дня) и «Обычная неделя» — один глагол «выживание»: это сама игра, а не отдельная миссия; оставлено сознательно.
- Типы «вождение» и «бой» в карточной игре не встречаются: для заданий дня «бой» — задание на скорость, «вождение» — разминка; в главах разминок проверка типов не применима.
- Разминки: двойники по механике оставлены (их 53, переделка — по одной); новые разминки с глаголами из этих пар не делать.
