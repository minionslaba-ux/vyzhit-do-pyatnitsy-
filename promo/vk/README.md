## 1. Создать группу — 5 минут

1. vk.com → слева **Сообщества** → **Создать сообщество** → **Группа по интересам** (или «Бренд или организация» → «Игра»).
2. Название: **Выжить до пятницы — игра про офис**
3. Тематика: **Компьютерные игры** (или «Развлечения»). Вид: **Открытая**.
4. Сайт: `https://survivefriday.com/?utm_source=vk`
5. Создать → **Управление**:
   - **Основная информация → Адрес страницы**: `survivefriday` (если занят — `vyzhitdopyatnitsy`, `survive_friday`, `survivefridaygame`).
   - **Описание** — текст из раздела 2.
   - **Обложка сообщества** → загрузить `cover-1920x768.png`.
   - Фото → `avatar-800.png`.
   - **Разделы**: включить «Стена — открытая/ограниченная», «Фотографии», «Обсуждения», «Видео». Товары и услуги не нужны.
   - **Кнопка действия** → «Открыть сайт» → `https://survivefriday.com/?utm_source=vk`.
   - **Ссылки** → добавить: `https://t.me/Survivefridaybot` — «Игра в Telegram».
6. Опубликовать приветственный пост (раздел 3) с картинкой `post-1-welcome.png` и **закрепить** его.

Когда группа будет создана — пришлите мне её адрес (например, `vk.com/survivefriday`): я впишу его в игру, и в меню появится кнопка «Мы во ВКонтакте».

## 5. Автопостинг: каждый день вместе с Telegram

Ежедневная рассылка бота (12:31 МСК) умеет публиковать пост и в группу ВК. По очереди: совет Миры → разминка дня → «Что бы вы выбрали?». К посту прикрепляется ссылка на игру с меткой `utm_source=vk`. Повторно в тот же день пост не выходит.

Чтобы включить (ключи мне не присылайте — добавьте сами):
1. В группе: **Управление → Работа с API → Ключи доступа → Создать ключ** → отметить **«Стена»** (и «Фотографии») → сохранить, подтвердить по СМС, скопировать ключ.
2. Там же, на странице «Работа с API», — числовой **ID группы** (или в адресе раздела «Управление»: `club123456789` → `123456789`).
3. Supabase → проект → **Edge Functions → Secrets** → добавить:
   - `VK_GROUP_TOKEN` = ключ из шага 1
   - `VK_GROUP_ID` = число из шага 2
4. Готово: со следующей ежедневной рассылки посты пойдут сами. Если что-то не так — в ответе функции `tg-daily` будет `vk: "error: …"`, напишите мне.

## 6. Как растить группу (бесплатно)

- Ставьте ссылку на группу в описании Telegram-бота и в постах групп раз в неделю.
- Опросы «Что бы вы выбрали?» — самые комментируемые посты; отвечайте на комментарии от имени группы.
- Мем-карточки финала из игры («Поделиться результатом») — просите игроков выкладывать их в комментарии.
- Конкурс раз в месяц: лучший результат недели дня → упоминание в посте.
- Метка `?utm_source=vk` во всех ссылках — в `survivefriday.com/?stats` видно, сколько игроков пришло из ВК.
